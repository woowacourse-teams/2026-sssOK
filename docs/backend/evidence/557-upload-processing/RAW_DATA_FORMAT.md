# 실험 원자료 보존 형식

자동 리뷰의 파일 수 제한을 피하기 위해 회차별 원시 CSV·메모리·CPU 파일을 `cli/run*.json`, `ffm/raw/results/run*.json`으로 묶었다. 각 파일의 이름, 원문 text, SHA-256을 그대로 보존했으며 역변환 해시를 확인했다.

비교 스크립트는 기존처럼 외부 결과 디렉터리에 CSV와 자원 파일을 생성한다. 이 JSON은 저장소에 보존하는 형식만 바꾼 것이며 측정값을 다시 계산하거나 표본을 제거하지 않았다. 재구성할 때 files의 각 항목 text를 해당 이름의 UTF-8 파일로 쓰면 된다.
