# 005 · 방 설정 (방장 전용)

**상태: 미구현**

## 목적

두 가지의 상황이 있다.

- 방장이 방을 처음 만들었을 때, 방 초기 설정을 진행한다.
- 방장이 방 이름 · 사라지는 시점 · 업로드 권한을 바꾸거나, 방을 아예 삭제하는 화면. 방장이 아닌 사람에게는 이 화면으로 가는 버튼 자체가 보이지 않는다.

## 진입 경로

- [001 홈](./001-home.md)에서 사진 공유방 만들기 버튼
- [003 갤러리](./003-gallery.md)에서 방장에게만 보이는 설정 버튼

## 다음 화면으로

- 초기 설정을 저장하면 → 닉네임 입력 창 → [003 갤러리](./003-gallery.md)로 이동한다.
- 설정을 저장하면 → [003 갤러리](./003-gallery.md)로 돌아간다. 바뀐 내용은 방에 있는 모든 사람에게 실시간으로 바로 반영된다.
- 방을 삭제하면 → [001 홈](./001-home.md)으로 이동한다. (방에 있던 모든 사람이 함께 이동)
