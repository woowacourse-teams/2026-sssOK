# 001 · 홈 / 사진 공유방 만들기

**상태: 미구현**

## 목적

새 방을 만드는 화면. 서비스에 링크 없이 처음 들어왔을 때, 또는 만료·존재하지 않는 방으로 들어왔을 때도 이 화면으로 안내된다.

## 진입 경로

- 서비스 주소로 직접 접속
- 잘못됐거나 만료된 링크·코드로 들어왔을 때 자동으로 안내

## 다음 화면으로

- 방을 새로 만들려면 → [005 방 설정](./005-room-settings.md)에서 초기 설정을 이어서 한다
- 코드로 기존 방에 들어가려면 → [002 방 입장](./002-room-entry.md)
