# 003 · 갤러리 (방 안)

**상태: 미구현**

## 목적

방에 들어온 뒤 가장 오래 머무는 화면. 사진·영상을 올리고, 모아 보고, 필요한 것만 고르고, 폴더로 정리하는 걸 전부 이 화면 안에서 처리한다.

## 진입 경로

- 방을 만든 사람: [005 방 설정](./005-room-settings.md)에서 초기 설정을 마쳤을 때
- 초대받은 사람: [002 방 입장](./002-room-entry.md)을 마쳤을 때

## 다음 화면으로

- 사진을 크게 보려고 누르면 → [004 라이트박스](./004-lightbox.md)
- 방장이 설정 아이콘을 누르면 → [005 방 설정](./005-room-settings.md)
- 업로드·선택·다운로드·폴더 이동은 별도 화면 전환 없이 이 화면 안에서 바로 처리된다.
