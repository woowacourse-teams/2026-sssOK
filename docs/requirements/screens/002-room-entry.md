# 002 · 방 입장

**상태: 미구현**

## 목적

초대받은 사람이 링크·코드·QR로 들어와서 방에 합류하기까지의 흐름. 화면 하나가 아니라, 상황에 따라 갈라지는 작은 화면들의 묶음이다.

- **닉네임 입력 창** — 이 방에 처음 들어온 사람에게 이름을 물어본다. (한 번만)
- **만료된 방 안내** — 이미 사라진 방으로 들어왔을 때 그 사실을 알려준다.

## 진입 경로

- 공유받은 초대 링크 클릭
- QR 코드 스캔
- [001 홈](./001-home.md)에서 8자리 코드 입력

## 다음 화면으로

- 정상적으로 입장하면 → 닉네임 입력 창 → [003 갤러리](./003-gallery.md)
- 만료됐거나 존재하지 않으면 → [001 홈](./001-home.md)으로 안내
