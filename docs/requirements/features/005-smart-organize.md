# 005 · 확장 — 알림 · 자동 정리 · 읽음 상태

1차 MVP는 당장 필요한 최소 기능(001~004)만 집중하고, 아래 기능들은 쏙을 카톡·슬랙과 다르게 만드는 확장 기능들이다. 사진이 한 공간에 모여 있다는 점을 활용해서, "옮기는 것"을 넘어 "정리해서 건네주는 것"까지 하려는 방향이다. 검증을 하면서 추후에 더 논의할 예정이다.

배경은 [RESEARCH.md](../RESEARCH.md)와 [VALIDATION-PLAN.md](../VALIDATION-PLAN.md)를 참고한다.

---

## 업로드 알림

**상태: 미정**

누군가 새 사진을 올리면 방에 있는 사람들에게 알려준다. 사람이 손으로 "새 사진 올라왔어요"라고 알려줬을 때 사람들이 실제로 다시 들어와서 사진을 확인한 것이 확인됐다. 검증된 아이디어 중 유일하게 효과가 확인된 것이라 가장 먼저 만든다.

- 새 사진이 올라오면 방 참여자에게 알림이 간다.
- 누가 올렸는지 표시한다.

## 안 읽은 사진 구분

**상태: 미정**

카카오톡의 "안 읽음" 표시처럼, 내가 아직 안 본 사진과 이미 본 사진을 구분해서 보여주는 아이디어다. 알림과 짝을 이루는 기능이라 함께 검토하되, 정확히 어떻게 구분선을 보여줄지는 아직 정해지지 않았다.

## AI 기반 자동 정리

**상태: 미정**

사진이 쌓일수록 사람이 직접 골라내는 일이 늘어난다. 이걸 자동으로 도와주는 아이디어다. 아직 검증되지 않았고, 아래 항목들은 하고 싶은 것의 예시일 뿐 확정된 목록이 아니다.

- 중복된 사진 자동으로 걸러내기
- 눈 감은 사진 자동으로 걸러내기
- 사람이 나온 사진만 골라서 다운로드하기
- 올린 사람별로 자동 분류하기
- 폴더까지 자동으로 만들어서 분류하기
