## 선택한 방법

**기존 얼굴 중심 사진의 기준을 유지하고, 작은 얼굴은 신체 근거가 있는 경우에만 새 그룹의 기준으로 추가한다.** 이번 자료에서 단순 완화와 같은 회수율을 얻으면서 배경 후보를 거를 추가 근거가 있는 방법이다. 보편적인 최적값으로 검증된 정책은 아니다.

- 얼굴 짧은 변 32px 이상, 기존 선명도·자세·검출 신뢰도 조건 유지.
- 기존 실패 조건이 얼굴 크기·전체 면적뿐인 경우에만 복구 검토. 다른 얼굴 대비 크기 조건은 유지.
- 같은 사진에서 얼굴과 신체가 모호하지 않게 연결되어야 한다. 신체가 여러 얼굴을 포함하거나 연결 후보의 위치 점수가 비슷하면 기준으로 사용하지 않는다.
- 신체 검출 점수 ≥0.8, 전체 사진 대비 신체 면적 ≥4%, 가장 큰 신체 대비 면적 ≥50%.
- 독립된 사진 2장 이상의 얼굴 근거로 그룹 생성. 얼굴 유사도 평균 0.45·최저 쌍 0.25는 변경하지 않는다.
- 이미 만들어진 그룹에는 작은 배경 얼굴도 기존 유사도·경쟁 그룹 점수 차이 기준으로 추가할 수 있다. 배경이라는 이유만으로 강제 제외하거나 강제 연결하지 않는다.
- 얼굴의 1차 추가 후 참조를 고정하고 완화된 자세 후보를 검토한다. 2차 후보끼리 연쇄 확장하지 않는다. 신체 보완도 얼굴로 연결된 참조를 고정하며 신체로 추가된 사진은 참조로 승격하지 않는다.

비슷한 얼굴 크롭을 중복 사진으로 취급하던 조건을 **사진 전체 중복 판정**으로 바꿨다. 96×96 축소 전체 영상의 평균 차이 ≤1.5, 8×8 타일별 최대 평균 차이 ≤6, 종횡비 차이 ≤1%를 모두 만족할 때만 같은 근거로 본다. 대표 사진은 고정해 중복 관계가 연쇄 확장되지 않게 한다. 복사본은 기존 그룹에 들어갈 수 있지만 그룹 생성·얼굴 비교·신체 참조의 독립 근거를 부풀리지 않는다.

정답은 전체 사진과 번호가 붙은 얼굴 크롭을 직접 보고 익명으로 작성했다. 알고리즘 출력을 정답으로 복사하지 않았다. 사용자 검수나 외부 평가자 합의는 받지 않은 잠정 시각 주석이다. 두 자료 모두 개발 중 결과를 확인했으므로, 회귀 자료를 임계값 선택과 완전히 독립된 블라인드 테스트라고 해석해서는 안 된다.

기존 자료에는 주요 인물로 식별하지 않은 배경 얼굴 18개와, 주요 인물이 다른 사진에서 배경에 등장한 얼굴 6개가 있다. 배경의 일부 얼굴은 작거나 옆·뒤를 향해 신원 판정이 불확실하다. 18개는 보수적으로 미확인 배경으로 취급하며, 고유한 배경 사람 18명을 뜻하지 않는다. 주요 인물의 배경 얼굴 6개는 최종 결과에서도 모두 보류됐다. 따라서 아래 주요 인물 회수율은 **배경에 작게 등장한 알려진 사람의 회수율을 포함하지 않는다.** 알려진 사람도 근거가 부족하면 보류하는 현재 동작이다.

사진·크롭·특징 벡터·사진별 주석은 공개 저장소에 포함하지 않는다. 기존 자료의 신체 특징을 재사용해 정책을 비교한 뒤, 최종 후보는 두 자료 모두 전처리부터 모델 추론까지 새로 실행해 동일한 결과를 확인했다.

## 실제 사진 비교

정밀도 = 올바른 인물–사진 연결 / 제안한 연결. 회수율 = 복구한 주요 인물–사진 연결 / 주요 연결 정답. 한 사진의 두 인물은 각각 1개 연결이다. 출력 그룹은 포함된 정답 얼굴의 최빈 인물로 대응시키며, 얼굴 단위 혼입과 같은 사람의 그룹 분할도 별도로 센다. 분할이 있으면 회수율의 동일 연결을 중복 계산하지 않는다.
