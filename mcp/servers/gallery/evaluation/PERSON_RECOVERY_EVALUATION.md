# 인물 분류 회수·오분류 개선 검증

## 범위
파이프라인 1.1.6-exposure-candidate. 원본 해상도 작은 얼굴 재검사, 저품질 얼굴 후속 회수,
얼굴과 충돌하는 몸통 연결 차단, 어두운 사진의 명암 재검사를 포함한다.
모델과 기준 얼굴을 교체하지 않고 회수된 얼굴을 새로운 기준으로 승격하지 않는다.
Spring API, DB, 결과·진행 계약, 배포 설정은 변경하지 않는다.

## 마지막 개선 단계 비교
다음 표는 PR 전체가 아닌, 이전 검증 후보 1.1.5 대비 마지막 보정 단계의 결과다.

| 데이터 | 정답 쌍 분모 | 이전 정답 회수 | 최종 정답 회수 | 이전→최종 라벨 불일치 |
|---|---:|---:|---:|---:|
| FEI 기존 두 묶음 | 1400 | 1378 | 1392 | 0→0 |
| 새 FEI | 700 | 670 | 674 | 14→14 |
| LFW | 13233 | 8851 | 8859 | 84→76 |

| 실제 앨범 A | 41 | 41 | 41 | 0→0 |

앨범 B의 미회수 5건은 얼굴 영역 정답이 없는 잠정 사진 단위 라벨이다.
Yale 변형은 독립 데이터로 세지 않는다. LFW 분모에는 독립 기준 사진 부족으로 그룹을 만들지 못한 사진도 포함된다.
LFW 불일치 제거 8건 중 라벨·영역 근거가 있는 오분류는 3건이고 나머지 5건은 불확실한 배정이다.
주변 얼굴의 라벨이 없으므로 76건 전체를 확정 오분류로 보거나 단순 전체 정밀도로 환산하지 않는다.

## 정책 선택과 검증
- 명암 확장, CLAHE, 감마 보정, 복수 방법 합의, 연결 차단 임계값 등 18개 정책을 비교했다.
- 보정 후 상위 독립 기준 사진 2장의 평균 유사도 0.65, 다른 그룹과 차이 0.15를 적용했다.
- 변환별 그룹 또는 얼굴 위치가 충돌하면 보류한다. 기존 특징과 기준 얼굴은 고정한다.
- 추가 몸통 차단은 단일 얼굴, 검출 점수 0.85 이상, 선명도 40 이상 및 나머지 기준 품질을 요구한다.
  독립 기준 사진 2장 이상과 비교한 최대 얼굴 유사도조차 0.30 미만일 때만 차단한다.
- 새 FEI 50명 700장은 기존 두 묶음과 인물 중복이 없다. 정책은 새 데이터 결과 확인 전에 고정했다.
- 전체 96개 묶음의 캐시 기반 비교에서 기존 정답 손실 및 새 라벨 불일치는 0건이었다.
- 실제 앨범 2개, LFW 1개, FEI 3개 등 총 6개 묶음을 원본부터 재실행해 배정 일치를 확인했다.
- 해당 6개 실행에서 추가 보정 단계는 약 0~0.84초였다. 운영 부하나 전체 처리시간의 보장은 아니다.
- 통합 소스 테스트 195개 통과. 합성·모의 테스트와 실제 이미지 추론 검증을 구분한다.

## 재현 및 데이터 취급
`mcp/servers/gallery`에서 의존성 설치 후 `python -m unittest discover -s tests -v`를 실행한다.
모델을 준비한 뒤 `python -m pipeline.run_local --input INPUT --output NEW_OUTPUT --assets-root MODELS --threads 2`로 원본 분석을 실행한다.
정확한 집계 재현에는 동일한 데이터 묶음과 비공개 정답·캐시가 필요하다. 공개 소스만으로 위 실측치를 재현할 수 있다고 주장하지 않는다.
사진, 얼굴 특징 벡터, 개인별 주석, 로컬 경로는 공개 저장소에 포함하지 않는다.
FEI는 공식 제공 데이터의 연구용 조건을 따른다.
